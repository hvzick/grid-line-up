# Grid Glory

i want to create a game for 1v1 players, (for now keep 1v1 vs bot and player too but player one we will implement later)
where there is a 5x5 matrix on both sides, each player can write 1 to 25 number in that where ever they want given that one cell in the matrix contains only one number, there should be 2 minutes to fill the matrix or else the empty cells will be filled randomly.
then after that the game starts first p1 turn, he selects a number on the matrix he should have max 15 seconds to selects one if he doesnt select then a number should be randomly selected, after that same p2 will do, now who ever completes 5 lines in vertical, horizontal and diagonal, he should win,
